# Команды, которые одобряются сразу на компьютере, без сообщения в Telegram.
# Строки с # — комментарии.
#
# Строка без звёздочки — эта команда плюс безобидные флаги, и ничего больше:
#   «git branch» пропустит «git branch -a», но не «git branch -D main»
#   и не «git branch новая» (аргумент, не флаг).
#   Флаги вроде -D, -d, -m, -f, --force, --output, --no-index не пропускаются
#   никогда: они удаляют, переименовывают или читают файлы вне репозитория.
# Строка со звёздочкой в конце («npm test *») пропускает любые аргументы —
#   добавляйте такие осознанно.
#
# Команда с &&, ;, |, >, <, $, скобками или обратной кавычкой список не
# проходит никогда.
# Намеренно НЕ добавляем cat/head/tail: иначе чтение любого файла,
# включая .env и ключи, одобрялось бы молча.
git status
git diff
git log
git branch
git remote -v
ls
dir
pwd
python -V
python --version
pip list
npm ls
